# カレンダーページ

このプロジェクトは、カレンダー機能を提供するウェブページです。

## 機能

- **今日の表示**: 現在の日付のところは文字が反転して表示されます
- **ナビゲーション**: 右上のプルダウンメニューで前後100年間のカレンダーを選択することができます。「今年」ボタンを押すと即座に現在の年に戻ることができ、左右の「前年（◀）」「次年（▶）」ボタンで1年ずつクイックに移動できます
- **今週・来週の2週間表示モード**: ヘッダーの表示切り替えタブ（`[年間]` / `[2週間]`）から、現在の日付（または年間カレンダーで選択した任意の日付）を基準とした「2週間（計14日間）」の拡大表示モードに切り替え可能です。
  - **年間カレンダーでクリックした週の表示**: 年間カレンダーで日付をクリックした状態で「2週間」タブに切り替えると、そのクリックした日の週とその翌週が表示されます（日付のダブルクリックでも直接その週の2週間表示にジャンプ可能）。過去や未来の週を表示しているときは、上部の「今週の表示に戻る」ボタンからワンクリックで現在週へ復帰できます。
  - **情報の常時表示（クリック不要）**: 日付をクリックしなくても、祝日名（🎌）、季節のイベント名、六曜、旧暦、月の満ち欠け（絵文字・名称・月齢）が各日のカード内に最初から見やすく常時表示されます。選択した日には青い枠線と「選択日」バッジが付きます。
  - **PC・タブレット・スマートフォン完全対応**: PCやタブレットでは全画面100%幅の7列均等カードグリッド、スマートフォンでは文字が潰れないよう「縦並びカードリスト形式」へ自動最適化されます。
  - **ISO週番号（W01〜W52/W53）の表示**: 各週のセクションヘッダー（「今週」「来週」の横）に、ISO 8601規格に準拠した週番号バッジ（例: `W42`）が表示されます。上部の期間表示（例: `2026年 10/11(日) 〜 10/24(土) (W42 - W43)`）や、各日のカード（ツールチップ）からも該当日の週番号を確認できます。
  - **既存設定との連動**: 週の開始曜日（日曜始まり/月曜始まり）、国選択（日本/アメリカ/イギリス）、多言語切替（日本語/English）、ダーク/ライトモードに完全連動します。選択内容はブラウザに保存され、URLパラメータ（例: `?view=2weeks&date=2026-05-03`）でも指定可能です。
- **和暦・干支の表示（日本カレンダーのみ）**: 日本のカレンダー選択時、ヘッダーに選択中の年の和暦と干支（十干十二支および動物の絵文字、例: `令和8年 丙午 (🐴)`）が表示されます。年のプルダウンメニューでも日本カレンダー選択時のみ和暦が併記されます（アメリカやイギリスのカレンダー選択時は西暦のみの表示となります）。
- **祝日の表示（日本・アメリカ・イギリス対応）**: ヘッダーの国選択プルダウンから、日本（🇯🇵）、アメリカ（🇺🇸）、イギリス（🇬🇧）の祝日を切り替えて表示できます。
  - **日本**: 内閣府の祝日データ「syukujitsu_utf8.csv」に基づき1955年以降の祝日を表示。データにない未来の祝日は現行法等に基づき自動推定。
  - **アメリカ**: 連邦祝日（Federal Holidays）および土日重複時の振替休日（Observed）に対応。
  - **イギリス**: イングランドおよびウェールズの主要バンクホリデー（イースター等の移動祝日や振替休日含む）に対応。
  - 選択した国はブラウザに保存され、URLパラメータ（例: `?country=us`, `?country=gb`, `?country=jp`）でも指定できます。
- **特定年のURL直接指定**: URLパラメータ（例: `?year=1974` または `?y=1974`）やハッシュ（例: `#1974`）を指定することで、特定の年のカレンダーを直接表示できます。また、年を変更するとURLも自動更新され、ブラウザの「戻る/進む」にも対応しています
- **ダークモード（デフォルト） / ライトモード対応**: デフォルトはダークモード表示です。ヘッダー右上のテーマ切替ボタン（☀️/🌙）でライトモードとダークモードをいつでも切り替えることができ、選択内容はブラウザに保存されます
- **月曜始まり・日曜始まりの切り替え**: ヘッダーの切り替えボタン（「月曜始まり」/「日曜始まり」）で、週の開始曜日をいつでも切り替えることができます。選択内容はブラウザに保存され、URLパラメータ（例: `?start=mon` / `?start=sun`）でも指定可能です（英語表示時は「Mon Start」/「Sun Start」に連動）。
- **六曜・旧暦・月の満ち欠け（月齢）の表示**: 日付にマウスオーバーまたはクリックすると、その日の情報がポップアップ表示されます。月の満ち欠け（名称、絵文字、月齢）および祝日名は全対象国で表示され、六曜（大安・友引など）および旧暦（旧暦X月Y日）は日本のカレンダーを表示しているときのみ表示されます。
- **年中行事・季節のイベント表示（日本カレンダーのみ）**: 祝日法上の祝日ではないイベント（節分、バレンタインデー、ひな祭り、ホワイトデー、母の日、父の日、七夕、お盆、ハロウィン、クリスマス、大晦日など）に対応。該当日には数字の下に小さなインジケーター（ドット）が表示され、マウスオーバーまたはクリックすると絵文字付きのイベント名がポップアップ表示されます（英語表示時も「Valentine's Day」「Christmas」などに連動）。
- **多言語対応（自動判定＆手動切替対応）**: 日本語ブラウザでアクセスした場合は日本語表示、それ以外の言語のブラウザでアクセスした場合は自動的に英語表示（見出し・月名・曜日・祝日名・干支・旧暦・六曜・月の満ち欠けなど）となります。また、ヘッダーの言語切替ボタン（「English」/「日本語」）をクリックすることで、いつでも手動で言語を即座に切り替えることができ、選択内容はブラウザに保存されます（URLパラメータ `?lang=en` / `?lang=ja` にも対応）。

## デプロイ（GitHub Pages）

- **自動デプロイ**: `v` から始まる Git タグ（例: `v1.0.0`）が push されると、GitHub Actions（`.github/workflows/deploy.yml`）が自動起動し、GitHub Pages へデプロイされます（GitHub の Actions タブから手動実行することも可能です）。
- **Google Analytics / GTM の設定**:
  - GitHub リポジトリの変数（Settings > Secrets and variables > Actions > Variables）に `GTM_ID`（例: `G-XXXXXXXXXX` または `GTM-XXXXXXX`）を設定しておくと、デプロイ時に Google Analytics のタグへ自動的に埋め込まれます。
  - `GTM_ID` が未設定の場合はトラッキングは行われず、エラー等も発生しません。
  - ローカル開発時は `config.js` に `window.GA_TRACKING_ID = '...';` または `window.GTM_ID = '...';` を記述することで利用可能です（`config.js` は `.gitignore` に指定されています）。

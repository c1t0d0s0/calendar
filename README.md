# カレンダーページ

このプロジェクトは、カレンダー機能を提供するウェブページです。

## 機能

- **今日の表示**: 現在の日付のところは文字が反転して表示されます
- **ナビゲーション**: 右上のプルダウンメニューで前後100年間のカレンダーを選択することができます。また、横の「今年」ボタンを押すと即座に現在の年に戻ることができます
- **和暦・干支の表示**: ヘッダーに選択中の年の和暦と干支（十干十二支および動物の絵文字、例: `令和8年 丙午 (🐴)`）が表示されます
- **祝日の表示**: 祝日の日の上にマウスカーソルを持っていくと祝日名が表示されます（内閣府の祝日データ「syukujitsu_utf8.csv」に基づき1955年以降の祝日を表示。データにない未来の祝日は現行法等に基づき自動推定され、フッターに推定である旨の注意書きが表示されます）
- **特定年のURL直接指定**: URLパラメータ（例: `?year=1974` または `?y=1974`）やハッシュ（例: `#1974`）を指定することで、特定の年のカレンダーを直接表示できます。また、年を変更するとURLも自動更新され、ブラウザの「戻る/進む」にも対応しています
- **ダークモード（デフォルト） / ライトモード対応**: デフォルトはダークモード表示です。ヘッダー右上のテーマ切替ボタン（☀️/🌙）でライトモードとダークモードをいつでも切り替えることができ、選択内容はブラウザに保存されます
- **六曜・旧暦・月の満ち欠け（月齢）の表示**: 日付にマウスオーバーまたはクリックすると、その日の六曜（大安・友引など）、旧暦（旧暦X月Y日）、月の満ち欠け（新月・三日月・上弦・満月・下弦などの名称、絵文字、月齢）および祝日名がポップアップ表示されます
